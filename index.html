About MINDORA

A focused study workspace, built to run locally.

MINDORA is a browser-based study tool. It does not connect to an AI service, cloud database, school account or external API. Quiz generation uses simple local rules and your saved notes and flashcards. Data is stored in browser storage and may be lost if browser site data is cleared, so export backups regularly. This single-file version does not synchronise data across devices.
